# Apresentacao - JobConnect Pro

## 1. Problema

Empresas precisam organizar vagas, candidaturas e etapas de selecao com rastreabilidade. Candidatos precisam acompanhar o andamento sem depender de mensagens soltas.

## 2. Solucao

JobConnect Pro centraliza empresas, vagas, curriculos, candidaturas e processos seletivos em uma plataforma responsiva com perfis de acesso.

## 3. Stack

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- ASP.NET Identity
- HTML, CSS e JavaScript
- ViaCEP e LinkedIn

## 4. Demonstracao

- Acessar a vitrine publica de vagas.
- Consultar CEP pela integracao ViaCEP.
- Validar URL publica do LinkedIn e compartilhar vaga.
- Entrar com usuario demo.
- Ver dashboard autenticado.
- Criar vaga para aprovacao.
- Candidatar-se como candidato demo.

## 5. Requisitos Atendidos

- Backend em .NET com SQL Server.
- No minimo tres endpoints publicos.
- No minimo tres endpoints autenticados.
- Frontend responsivo e personalizado.
- Controle de versao de codigo com Git.
- Controle de versao de banco com migrations.
- Consumo de APIs de terceiros.
